# Privacy Policy for Library Manager

This app is for personal library or School to manage library inventory and book checkouts.

## Information We Collect:
- Book inventory data
- Checkout and return dates

## How We Use Information:
- To manage library book checkouts and returns
- To track library inventory

## Third-Party Services:
- We use Google Books API to retrieve book information

## Data Storage:
- All data is stored locally on the device
